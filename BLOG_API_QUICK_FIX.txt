  BLOG API FIX - QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

ISSUE: "Blog not found" error, API not being called

ROOT CAUSE: Relative API paths not working correctly

SOLUTION: Changed to absolute URLs using window.location.origin

═══════════════════════════════════════════════════════════════════════════════

WHAT WAS CHANGED
═══════════════════════════════════════════════════════════════════════════════

FILE: blogPageDetails.php

CHANGE 1: Main Blog Loading
  BEFORE: let apiUrl = `/api/get_blogs_working.php?lang=${lang}`;
  AFTER:  let apiUrl = `${window.location.origin}/api/get_blogs_working.php?lang=${lang}`;

CHANGE 2: Related Blogs
  BEFORE: const response = await fetch(`/api/get_blogs.php?limit=3&lang=${lang}`);
  AFTER:  const apiUrl = `${window.location.origin}/api/get_blogs.php?limit=3&lang=${lang}`;
          const response = await fetch(apiUrl);

CHANGE 3: Blog Redirect
  BEFORE: fetch(`/api/get_blogs.php?lang=${lang}&id=${blogId}`)
  AFTER:  const apiUrl = `${window.location.origin}/api/get_blogs.php?lang=${lang}&id=${blogId}`;
          fetch(apiUrl)

CHANGE 4: Added Logging
  Added console.log() for debugging API calls
