───────────────────────────────────────────────────────────────────────────────
ROOT CAUSE
───────────────────────────────────────────────────────────────────────────────

1. Z-INDEX CONFLICT
   - Menu z-index: 999
   - Header z-index: 1000
   - Result: Menu behind header (invisible)

2. DUAL JAVASCRIPT HANDLERS
   - app-header.js (modern, class-based)
   - navbar-mobile-toggle.js (fallback)
   - Result: Race conditions, conflicting behavior

───────────────────────────────────────────────────────────────────────────────
FIXES APPLIED
───────────────────────────────────────────────────────────────────────────────

File: assest/app-header.css
Lines: 354-360, 467-472, 478-483

BEFORE:

      z-index: 999;  ← TOO LOW
  }

AFTER:
  .app-nav.app-nav--active {
      z-index: 1001;  ← NOW HIGHER THAN HEADER
  }

───────────────────────────────────────────────────────────────────────────────

FIX #2: REMOVE CONFLICTING JAVASCRIPT
File: index.php
