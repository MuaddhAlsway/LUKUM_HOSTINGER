STEP 7: IF API STILL RETURNS 500 ERROR

If api/get_blogs_working.php still returns 500:

   If shows error:

   - Check api/config.php credentials
   - Verify database is running

2. Check server error logs:
   - In Hostinger control panel
   - Find: Error Logs or Logs
   - Look for PHP errors
   - Check what's causing the 500 error

3. Check if database tables exist:
   - In Hostinger control panel
   - Find: MySQL Databases
   - Open phpMyAdmin
   - Check if tables exist: events, blogs, press

TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────

Problem: Still getting 404 for event.php
Solution: 
  1. Verify file was uploaded to public_html (not a subfolder)
  2. Check file name is exactly: event.php (lowercase)
  3. Try refreshing browser (Ctrl+F5)
  4. Clear browser cache

Problem: API returns 500 error
Solution:
  1. Check database connection in api/config.php
  2. Verify database credentials are correct
  3. Check if database tables exist
  4. Check server error logs for PHP errors
  5. Verify api/get_blogs_working.php was uploaded correctly

Problem: Blog page shows "Check back soon for articles and stories"
Solution:
  1. This means API is failing (500 error)
  2. Follow "API returns 500 error" solution above
  3. Or database has no blogs - add blogs to database

Problem: Font 404 error (greta-arabic.css)
Solution:
  1. This is not critical - just a missing font file
  2. Upload missing fonts to: public_html/fonts/
  3. Or ignore - site will still work without this font
