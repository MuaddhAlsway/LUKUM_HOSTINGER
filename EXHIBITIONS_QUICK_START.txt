STEP-BY-STEP SETUP
═══════════════════════════════════════════════════════════════════════════════

1. CREATE DATABASE TABLE (ONE TIME ONLY)
   ───────────────────────────────────────
   📍 Visit: http://localhost/api/create_exhibitions_table.php
   
   Expected response:
   {"success": true, "message": "Exhibitions table created successfully"}


2. ACCESS ADMIN PANEL
   ───────────────────────────────────────
   📍 Go to: http://localhost/admin/dashboard.html
   📍 Look for "Exhibitions" in left sidebar (between Site Settings and Events)
   📍 Click "Exhibitions" tab


3. ADD YOUR FIRST EXHIBITION
   ───────────────────────────────────────
   📍 Click "Add Exhibition" button
   
   Fill in:
   • Exhibition Title (English) - REQUIRED
   • Exhibition Date - REQUIRED
   • Location - REQUIRED
   • Cover Image (optional)
   • Arabic translation (optional)
   
   Then click "Create Exhibition"


4. VIEW ON WEBSITE
   ───────────────────────────────────────
   📍 Visit: http://localhost/spaces.php
   📍 Scroll down to "Past Events" section
   📍 Your exhibition should appear in the carousel (if date is in the past)

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ "Database connection failed"
→ Make sure XAMPP is running and Apache/MySQL are started

❌ Exhibitions don't appear on spaces.php
→ Make sure you used a PAST date for exhibition_date
→ Check browser console (F12) for fetch errors

❌ Table already exists error
→ That's OK! Just means the table was already created
→ You can add exhibitions normally

❌ Images not uploading
→ Check /uploads/ folder exists and is writable
→ Check PHP file upload limits
