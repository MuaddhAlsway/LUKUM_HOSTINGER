SQL COMMANDS EXECUTED
════════════════════════════════════════════════════════════════════════════

STEP 1: Add event_video Column
───────────────────────────────────────────────────────────────────────────
  ALTER TABLE exhibitions 
    ADD COLUMN `event_video` VARCHAR(500) 
    AFTER `cover_image`;

  Purpose: Store single video URL (YouTube, Vimeo, or direct file)
  Size: 500 characters max
  Example: "https://www.youtube.com/embed/abc123xyz"


STEP 2: Add gallery_images Column
───────────────────────────────────────────────────────────────────────────
  ALTER TABLE exhibitions 
    ADD COLUMN `gallery_images` LONGTEXT 
    AFTER `event_video`;

  Purpose: Store gallery images as JSON array
  Size: Up to 100+ images per exhibition
  Example: ["assest/img-1.jpg", "assest/img-2.jpg", "assest/img-3.jpg"]

COLUMN SPECIFICATIONS
════════════════════════════════════════════════════════════════════════════

event_video Column:
  Type:       VARCHAR(500)
  Nullable:   YES (NULL if not provided)
  Default:    NULL
  Position:   After cover_image
  Usage:      Single video URL storage
  Examples:
    - https://www.youtube.com/embed/video_id
    - https://vimeo.com/video_id
    - assest/videos/exhibition.mp4


gallery_images Column:
  Type:       LONGTEXT (up to 4GB)
  Nullable:   YES (NULL if no gallery)
  Default:    NULL
  Position:   After event_video
  Usage:      JSON array of image paths
  Format:     ["path1.jpg", "path2.jpg", ...]
  Examples:
    - ["assest/img-1.jpg"]
    - ["assest/img-1.jpg", "assest/img-2.jpg", "assest/img-3.jpg"]
    - ["assest/gallery/photo1.jpg", "assest/gallery/photo2.jpg", ...]
