STEP 4: Based on Your Console Output
════════════════════════════════════

CASE 1: Both sections visible, but video not on page
─────────────────────────────────────────────────
ACTION:
  1. Press F12 again to close DevTools
  2. Look for "Event Video" section heading on page
  3. If visible: Video should be below it
  4. If NOT visible: CSS not working
  
TO FIX:
  1. Open DevTools (F12)
  2. Click Inspector/Elements tab
  3. Press Ctrl+F and search: "videoSection"
  4. Click on the result
  5. Check if element has class "active" in <section> tag
  6. Right side should show: event-section--video.active { display: block !important; }


CASE 2: Only Section A visible, Section B NOT visible
──────────────────────────────────────────────────────
ACTION:
  1. Check console for error messages (red X icons)
  2. Look for: "Uncaught ReferenceError: displayVideo is not defined"
  3. Look for: "Cannot read property 'classList' of null"

TO FIX:
  1. Check if event-detail.css is loading (Network tab)
  2. Check if event.php file has displayVideo() function
  3. Check for JavaScript errors elsewhere


CASE 3: No "=== VIDEO URL CHECK ===" section at all
────────────────────────────────────────────────────
ACTION:
  1. Check Network tab (F12 → Network)
  2. Reload page
  3. Look for: "get_event_details.php" request
  4. Click on it, check Response tab
  5. Look for "event_video" field

TO FIX:
  1. If field missing from API: edit get_event_details.php
  2. If API call not made: check loadEventData() function
  3. If API error: check database connection


CASE 4: "event_video: null" in Section A
─────────────────────────────────────────
ACTION:
  1. Check database directly (STEP 1)
  2. If NULL in database: video wasn't saved
  
TO FIX IF DATABASE HAS NULL:
  1. Edit exhibition in admin panel
  2. Clear cache (Ctrl+Shift+Delete)
  3. Add video URL again
  4. Make sure field is not disabled
  5. Check browser console while adding
  6. Look for: "event_video value from form: https://..."
