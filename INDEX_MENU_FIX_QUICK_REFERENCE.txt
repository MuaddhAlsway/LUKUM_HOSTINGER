PROBLEM
══════════════════════════════════════════════════════════════════════════════

On index.php ONLY, mobile menu was invisible when clicked

Why only index.php?
  - index.php had z-index: 0 on .lakum-hero
  - Other pages (blog.php, about.php) didn't have this
  - Result: Menu trapped behind hero on index.php only


ROOT CAUSE: Z-INDEX STACKING CONTEXT
══════════════════════════════════════════════════════════════════════════════

Z-Index Stacking Context Problem:

  When you set z-index on a positioned element, it creates a STACKING CONTEXT
  All children are trapped inside that context, regardless of their z-index

  Example:
    .lakum-hero { z-index: 0; }  ← Creates stacking context barrier
    .lakum-nav { z-index: 999; } ← Trapped inside hero's context!

  Result: Menu (z-index: 999) can't escape hero's context (z-index: 0)


Z-INDEX HIERARCHY (BEFORE)
══════════════════════════════════════════════════════════════════════════════

  Page Loader (z-index: 9999) ✓ Visible
  Header (z-index: 1000) ✓ Visible
  Hero (z-index: 0) ← Creates stacking context barrier
    ├─ Hero Image Wrapper (z-index: -1)
    ├─ Hero Overlay (z-index: 0)
    └─ Hero Content (z-index: 1)
  Mobile Menu (z-index: 999) ❌ TRAPPED inside hero context


SOLUTION
══════════════════════════════════════════════════════════════════════════════

Removed z-index from hero-related classes in index.php:

  1. .lakum-hero
     BEFORE: z-index: 0;
     AFTER: (removed)

  2. .lakum-hero__image-wrapper
     BEFORE: z-index: -1;
     AFTER: (removed)

  3. .lakum-hero__overlay
     BEFORE: z-index: 0;
     AFTER: (removed)

  4. .lakum-hero__content
     BEFORE: z-index: 1;
     AFTER: (removed)

Result: No stacking context barrier, menu can appear on top!


Z-INDEX HIERARCHY (AFTER)
══════════════════════════════════════════════════════════════════════════════

  Page Loader (z-index: 9999) ✓ Visible
  Header (z-index: 1000) ✓ Visible
  Mobile Menu (z-index: 999) ✓ VISIBLE (no barrier)
  Hero (no z-index) ✓ Below menu naturally
    ├─ Hero Image Wrapper (no z-index)
    ├─ Hero Overlay (no z-index)
    └─ Hero Content (no z-index)

WHY THIS ONLY AFFECTED INDEX.PHP
══════════════════════════════════════════════════════════════════════════════

index.php had explicit z-index values:
  .lakum-hero { z-index: 0; }
  .lakum-hero__image-wrapper { z-index: -1; }
  .lakum-hero__overlay { z-index: 0; }
  .lakum-hero__content { z-index: 1; }

Other pages (blog.php, about.php) didn't have these:
  .event-hero { /* no z-index */ }
  .event-hero__image-wrapper { /* no z-index */ }
  .event-hero__overlay { /* no z-index */ }
  .event-hero__content { /* no z-index */ }

Result: Menu worked on other pages but not index.php
