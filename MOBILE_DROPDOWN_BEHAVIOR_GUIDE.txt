================================================================================
MOBILE DROPDOWN MENU - BEHAVIOR COMPARISON & FIX DETAILS
================================================================================

PROBLEM IDENTIFIED:
  Mobile dropdown menu behavior was inconsistent with desktop experience
  Toggle button positioning was unclear
  Dropdown expansion didn't feel natural

ROOT CAUSE ANALYSIS:
  1. Toggle button used flex order property in column layout
  2. margin-left: auto doesn't work properly with flex-direction: column
  3. No clear visual separation between link and dropdown
  4. Missing visual hierarchy feedback

ARCHITECTURE AFTER FIX
================================================================================

MOBILE CSS AFTER FIX (@media max-width: 820px):

    position: relative;      ← Needed for absolute toggle positioning

FLEX LAYOUT EXPLANATION
================================================================================

DESKTOP (flex-direction: row):
  
  <li class="lakum-nav__item--dropdown">
    ├─ <a class="lakum-nav__link">Home</a>  ← order: not set (default 0)
    └─ <button class="lakum-nav__dropdown-toggle">▼</button>  ← order: not set
  
  Visual (row direction):
  [Link] [Arrow] ← Side by side!
  
  ▼ Dropdown (absolute positioning):
  [  List  ]  ← Floats below

MOBILE BEFORE (flex-direction: column - WRONG):
  
  <li class="lakum-nav__item--dropdown">
    ├─ <a class="lakum-nav__link">Home</a>  ← flex: 1, no width limit
    ├─ <button class="lakum-nav__dropdown-toggle">▼</button>  ← order: 1, margin-left: auto
    └─ <ul class="lakum-nav__dropdown">...</ul>  ← order: 2
  
  Visual (column direction + margin-left: auto on 2nd child):
  [Home.........................▼]  ← margin-left: auto doesn't work!
  [Items...]  ← All below
  
  PROBLEM: margin-left: auto doesn't position element to right in column flex.
           It just pushes flex-start direction (doesn't change layout).

MOBILE AFTER (flex-direction: column + absolute positioning - CORRECT):
  
  <li class="lakum-nav__item--dropdown">  ← position: relative (enables absolute child positioning)
    ├─ <a class="lakum-nav__link">Home</a>  ← width: calc(100% - 50px)
    ├─ <button class="lakum-nav__dropdown-toggle">▼</button>  ← position: absolute; right: 0; top: 0;
    └─ <ul class="lakum-nav__dropdown">...</ul>
  
  Visual:
  [Home........................][▼]  ← Toggle absolutely positioned on right
  [Items...]  ← All below
  
  SOLUTION: Use absolute positioning for toggle = no need for flex ordering!
           Parent stays flex column, toggle positioned absolutely.

JAVASCRIPT BEHAVIOR (Unchanged but now has proper CSS target)
================================================================================

Click Handler:
  1. User clicks .lakum-nav__dropdown-toggle button
  2. JavaScript finds parent .lakum-nav__item--dropdown
  3. Adds/removes .active class
  4. CSS rules trigger:
     .lakum-nav__item--dropdown.active .lakum-nav__dropdown {
       opacity: 1;
       max-height: 500px;
     }
  5. Transition property animates the change smoothly

Close Handler:
  1. User clicks outside menu → closeAllDropdowns()
  2. User presses ESC key → closeAllDropdowns()
  3. User clicks on dropdown link → closeAllDropdowns()
  
  closeAllDropdowns() removes .active class from all items
  CSS transitions opacity and max-height back to 0

Result: Smooth, natural dropdown behavior on both desktop and mobile!
