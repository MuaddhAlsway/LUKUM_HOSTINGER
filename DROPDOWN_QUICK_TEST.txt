================================================================================
COMMON ISSUES & FIXES
================================================================================

ISSUE #1: Dropdown still not showing
SOLUTION: 
- Check console for red errors (F12)
- Make sure window is > 1025px wide
- Hard refresh: Ctrl+Shift+R
- Check if JavaScript is enabled in browser

ISSUE #2: Dropdown showing but in wrong place
SOLUTION:
- This shouldn't happen - CSS positioning is fixed
- If it does, hard refresh browser cache
- Check browser DevTools (F12) → Elements → Find .lakum-nav__dropdown
- Verify it has: position: absolute, top: calc(100% + 8px)

ISSUE #3: Clicking outside doesn't close it
SOLUTION:
- This was the bug we fixed!
- Make sure CSS version is 2.4.0 (not 2.2.0)
- Hard refresh: Ctrl+Shift+R
- Try different browser to rule out cache issue

ISSUE #4: Arrow doesn't rotate
SOLUTION:
- CSS should rotate arrow when dropdown is active
- Check browser DevTools (F12) → Elements
- Find .lakum-nav__dropdown-toggle
- When active, it should have: transform: rotate(180deg)

ISSUE #5: Mobile still broken
SOLUTION:
- The fix was for DESKTOP only (1025px+)
- Mobile should work same as before
- If mobile is broken, it's a separate issue
