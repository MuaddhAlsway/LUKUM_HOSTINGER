================================================================================
  TROUBLESHOOTING
================================================================================

Images Not Loading:
  1. Check file paths in HTML
  2. Verify optimized-images/ directory exists
  3. Check file permissions (644)
  4. Check browser console for errors

WebP Not Loading:
  1. Check browser support
  2. Verify WebP files generated
  3. Check image optimizer output
  4. Use <picture> element for fallback

Slow Loading:
  1. Check image sizes
  2. Verify compression applied
  3. Check network tab in DevTools
  4. Consider CDN for images
