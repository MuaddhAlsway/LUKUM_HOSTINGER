THE PROBLEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

User Complaint:
"Dropdown showing on the LEFT side for BOTH English and Arabic!
It should be:
  - BELOW the header (not at top)
  - English (LTR): LEFT side, aligned with clicked item
  - Arabic (RTL): RIGHT side, aligned with clicked item"

Root Cause:
CSS had HARDCODED positioning values with !important:
  .lakum-nav__dropdown {
    top: 0 !important;          ← PROBLEM: Fixed to top
    left: 0 !important;          ← PROBLEM: Fixed to left
    right: auto !important;      ← PROBLEM: For RTL
  }

These CSS values were OVERRIDING the JavaScript calculations!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
THE SOLUTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STRATEGY: Separate CSS concerns from JavaScript concerns
────────────────────────────────────────────────────────

CSS ROLE (lakum-dropdown-override.css v1.1.0):
  ✓ Sets position: fixed (for fixed viewport positioning)
  ✓ Sets styling: background, border, shadow, z-index, padding, etc.
  ✗ DOES NOT set: top, left, right (hardcoded values)
  → Comment added: "JavaScript controls positioning dynamically"

JavaScript ROLE (js/lakum-header-dropdowns.js):
  ✓ Calculates header height
  ✓ Gets clicked item position
  ✓ Detects language direction (RTL/LTR)
  ✓ Sets top, left, right values dynamically
  ✓ Clears old styles first (removeProperty)
  ✓ Repositions on window resize

RESULT: No CSS/JS conflicts, proper positioning achieved!

3. js/lakum-header-dropdowns.js (NO VERSION CHANGE)
   ────────────────────────────────────────────────
   ENHANCED: positionDropdown() function

   BEFORE (v3.2.0):
   ────────────────
   function positionDropdown(dropdownItem) {
     const dropdown = dropdownItem.querySelector('.lakum-nav__dropdown');
     const rect = dropdownItem.getBoundingClientRect();
     const top = headerHeight + 10;
     
     dropdown.style.position = 'fixed';
     dropdown.style.top = top + 'px';
     dropdown.style.left = left + 'px';  ← Didn't clear old styles
     dropdown.style.right = right + 'px';
   }

   AFTER (v1.1.0):
   ───────────────
   function positionDropdown(dropdownItem) {
     const dropdown = dropdownItem.querySelector('.lakum-nav__dropdown');
     
     // STEP 1: Clear old positioning first!
     dropdown.style.removeProperty('top');    ← NEW
     dropdown.style.removeProperty('left');   ← NEW
     dropdown.style.removeProperty('right');  ← NEW
     
     // STEP 2: Calculate positions
     const top = headerHeight + 10;
     const rect = dropdownItem.getBoundingClientRect();
     const isRTL = document.documentElement.dir === 'rtl';
     
     // STEP 3: Apply new positioning
     dropdown.style.top = top + 'px';
     
     if (isRTL) {
       const rightOffset = window.innerWidth - rect.right;
       dropdown.style.right = rightOffset + 'px';
       dropdown.style.left = 'auto';
     } else {
       dropdown.style.left = rect.left + 'px';
       dropdown.style.right = 'auto';
     }
   }
