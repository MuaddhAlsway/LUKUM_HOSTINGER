WHAT CHANGED:
─────────────

PROBLEM: Dropdown always appeared at viewport top-left (0,0)
         For BOTH English AND Arabic
         Not positioned below header
         Not aligned with nav item

ROOT CAUSE: CSS files had hardcoded top/left values with !important
            These overrode JavaScript positioning calculations

SOLUTION: Removed hardcoded positioning from CSS
          Let JavaScript control dynamic positioning
          Result: Dropdowns now properly positioned

IMPACT:   ✅ English: Dropdown on LEFT side
          ✅ Arabic: Dropdown on RIGHT side
          ✅ Both: Below header
          ✅ Both: Aligned with nav item
          ✅ Both: Responsive and accessible
