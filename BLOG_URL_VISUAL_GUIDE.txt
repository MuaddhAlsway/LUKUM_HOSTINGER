┌────────────────────────────────────────────────────────────────────────────┐
│ URL STRUCTURE                                                              │
└────────────────────────────────────────────────────────────────────────────┘

  blogPageDetails.php?title={encoded_title}&lang={language}
  
  ├─ title: URL-encoded blog title
  │  ├─ English: "Behind the Scenes" → "Behind%20the%20Scenes"
  │  └─ Arabic: "خلف الكواليس" → "%D8%AE%D9%84%D9%81%20%D8%A7%D9%84%D9%83%D9%88%D8%A7%D9%84%D9%8A%D8%B3"
  │
  └─ lang: Language code
     ├─ en: English (LTR text direction)
     └─ ar: Arabic (RTL text direction)

┌────────────────────────────────────────────────────────────────────────────┐
│ SYSTEM FLOW                                                                │
└────────────────────────────────────────────────────────────────────────────┘

  BLOG LISTING (blog.php)
  ├─ Displays all blog posts
  ├─ User clicks blog card
  ├─ getBlogUrl() generates URL with:
  │  ├─ Encoded title
  │  └─ Current language
  └─ Navigates to blogPageDetails.php?title=...&lang=...
         ↓
  BLOG DETAIL (blogPageDetails.php)
  ├─ Extracts title and lang parameters
  ├─ Fetches blog from API with lang parameter
  ├─ Displays blog in correct language
  ├─ Sets text direction (RTL for Arabic, LTR for English)
  └─ Shows related blogs with same language
         ↓
  API (api/get_blogs_working.php)
  ├─ Receives lang parameter
  ├─ Selects language-specific content:
  │  ├─ If lang=ar: Return Arabic content
  │  └─ If lang=en: Return English content
  └─ Returns blog data with correct language


┌────────────────────────────────────────────────────────────────────────────┐
│ LANGUAGE PARAMETER PRIORITY                                               │
└────────────────────────────────────────────────────────────────────────────┘

  1. URL Parameter (?lang=ar or ?lang=en)
     └─ Highest priority
  
  2. Window Language (window.LAKUM_LANG)
     └─ Set by JavaScript
  
  3. LocalStorage (lakum_language)
     └─ User's saved preference
  
  4. Default (en)
     └─ Fallback to English


┌────────────────────────────────────────────────────────────────────────────┐
│ TEXT DIRECTION                                                             │
└────────────────────────────────────────────────────────────────────────────┘

  ENGLISH (?lang=en)
  ├─ Direction: LTR (Left-to-Right)
  ├─ Text alignment: Left
  └─ Example: "Behind the Scenes" →

  ARABIC (?lang=ar)
  ├─ Direction: RTL (Right-to-Left)
  ├─ Text alignment: Right
  └─ Example: ← "خلف الكواليس"
