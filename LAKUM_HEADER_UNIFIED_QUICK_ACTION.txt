================================================================================
TROUBLESHOOTING
================================================================================

Issue: Header not displaying
→ Check if lakum-header-unified.php is included in the page

Issue: Styles not applying
→ Verify lakum-header-unified.css is loaded FIRST in stylesheets.php

Issue: Mobile menu not working
→ Check if lakum-header-unified.js is loaded in scripts.php

Issue: Language switcher not working
→ Verify buildLanguageSwitcherUrl() function exists in lang/loader.php

Issue: Active link not highlighting
→ Check if basename($_SERVER['PHP_SELF']) matches page filename
