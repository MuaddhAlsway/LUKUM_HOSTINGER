───────────────────────────────────────────────────────────────────────────────

1. Go to: /admin/exhibitions.html

3. Click: Edit button (pencil icon)

4. Scroll down to: "Event Video (Optional)"

5. Paste your video URL:

   └─ Or: Any other video URL

6. Click: "Update Exhibition"

7. Done! ✓


VERIFY IT WORKED:

1. Go to: /spaces.php

3. Click: "Cheval Blanc" exhibition

5. Video should be playing ✓

   id=54, title_en="Cheval Blanc", event_video="https://..."

2. Check API response:
   Go to event page → F12 → Network → get_event_details.php
   
   Should have: "video_url": "https://..."

3. Check browser console:
   F12 → Console
