================================================================================
EXHIBITIONS TABLE - QUICK REFERENCE
Based on Admin Panel Form Fields
================================================================================

TABLE NAME: exhibitions

================================================================================
COLUMNS (Fields)
================================================================================

ENGLISH CONTENT (Required):
  • title_en VARCHAR(255) - Exhibition title in English *REQUIRED*
  • description_en LONGTEXT - Exhibition description in English
  • location_en VARCHAR(255) - Location (Hall 1, Hall 2, Café, Meeting Room) *REQUIRED*

ARABIC CONTENT (Optional):
  • title_ar VARCHAR(255) - Exhibition title in Arabic
  • description_ar LONGTEXT - Exhibition description in Arabic
  • location_ar VARCHAR(255) - Location in Arabic (القاعة 1, الكافيه, etc.)

DATE & TIME:
  • exhibition_date DATE - Start date (Past dates only) *REQUIRED*
  • exhibition_time TIME - Start time (e.g., 10:00:00) Default: 10:00
  • exhibition_end_time TIME - End time (e.g., 18:00:00) Default: 18:00
  • end_date DATE - End date for multi-day exhibitions (optional)

MEDIA:
  • cover_image VARCHAR(500) - Path to cover image (e.g., assest/img-4.png)

METADATA:
  • category VARCHAR(50) - Type: always 'exhibition' (fixed)
  • is_featured TINYINT(1) - Featured on homepage (0=no, 1=yes)

AUTO-GENERATED:
  • id INT - Unique exhibition ID (auto-increment)
  • created_at TIMESTAMP - Date/time created (auto)
  • updated_at TIMESTAMP - Date/time last updated (auto)

================================================================================
LOCATIONS AVAILABLE
================================================================================
  • Hall 1
  • Hall 2
  • Café
  • Meeting Room
  • Custom (user can enter custom location)

================================================================================
COMMON QUERIES
================================================================================

Get all exhibitions (newest first):
  SELECT * FROM exhibitions ORDER BY exhibition_date DESC;

Get featured exhibitions:
  SELECT * FROM exhibitions WHERE is_featured = 1;

Get by location:
  SELECT * FROM exhibitions WHERE location_en = 'Hall 1';

Search by title:
  SELECT * FROM exhibitions WHERE title_en LIKE '%Contemporary%';

Get exhibitions in date range:
  SELECT * FROM exhibitions 
  WHERE exhibition_date BETWEEN '2025-01-01' AND '2025-12-31'
  ORDER BY exhibition_date ASC;

Count exhibitions:
  SELECT COUNT(*) as total FROM exhibitions;

================================================================================
IMPORTANT NOTES
================================================================================

✓ DO:
  • Use bilingual content (English & Arabic) for international audience
  • Always provide exhibition_date (required field)
  • Use existing locations when possible (Hall 1, Hall 2, Café, Meeting Room)
  • Set cover_image path (e.g., assest/img-4.png)
  • Use is_featured = 1 for homepage highlights

✗ DON'T:
  • Leave title_en or location_en empty
  • Use future dates (only past dates allowed)
  • Mix languages in one field
  • Hardcode image URLs (use assest/folder/image.png format)

================================================================================
TECHNICAL DETAILS
================================================================================

Database Engine: InnoDB
Character Set: utf8mb4 (Supports Arabic, Emoji)
Collation: utf8mb4_unicode_ci

Indexes:
  • idx_exhibition_date - Speed up date queries
  • idx_category - Speed up category filter
  • idx_is_featured - Speed up featured query

Auto-Increment ID: Starts at 1, increments by 1

Timestamps: 
  • created_at - Set once at creation, never changes
  • updated_at - Auto-updates whenever record is modified
