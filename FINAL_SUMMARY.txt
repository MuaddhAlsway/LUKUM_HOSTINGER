⚠️  WHAT YOU NEED TO DO (1.5-2.5 hours)
═══════════════════════════════════════════════════════════════════════════════════

STEP 1: GENERATE IMAGE VARIANTS (1-2 hours)
────────────────────────────────────────────

Choose ONE method:

A) AUTOMATED (Recommended)
   macOS/Linux:
     $ brew install ffmpeg
     $ chmod +x convert-images.sh
     $ ./convert-images.sh

   Windows:
     > choco install ffmpeg
     > convert-images.bat

B) MANUAL FFmpeg
   $ ffmpeg -i heroImage/img-4.png -vf "scale=320:-1" -q:v 65 heroImage/img-4-320w.webp
   $ ffmpeg -i heroImage/img-4.png -vf "scale=320:-1" -c:v libaom-av1 -crf 50 heroImage/img-4-320w.avif
   (Repeat for 480w, 768w, 1200w)

C) ONLINE
   1. Go to: https://cloudconvert.com/
   2. Upload images
   3. Convert to WebP (q=65) + AVIF (q=50)
   4. Download all sizes (320w, 480w, 768w, 1200w)

STEP 2: DELETE OVERSIZED ORIGINALS (5 minutes)
───────────────────────────────────────────────

macOS/Linux:
  $ rm heroImage/img-4.png
  $ rm heroImage/img-3.png
  $ rm assest/img-4.png
  $ rm assest/img-3.png

Windows (PowerShell):
  > Remove-Item heroImage/img-4.png
  > Remove-Item heroImage/img-3.png
  > Remove-Item assest/img-4.png
  > Remove-Item assest/img-3.png

STEP 3: VERIFY IN BROWSER (10 minutes)
──────────────────────────────────────

1. Open DevTools (F12)
2. Go to Network tab
3. Reload page
4. Check:
   ✓ Only ONE hero image downloaded
   ✓ File size <150KB
   ✓ Format is WebP or AVIF
   ✓ No 404 errors

STEP 4: RUN LIGHTHOUSE AUDIT (5 minutes)
────────────────────────────────────────

1. DevTools → Lighthouse
2. Run audit (Mobile)
3. Verify:
   ✓ LCP: <2.5s (was 4-5s)
   ✓ Lighthouse: >85 (was 35)
   ✓ Total payload: <1.5MB (was 8.7MB)
