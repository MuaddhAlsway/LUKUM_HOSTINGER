================================================================================
MOBILE-FIRST APPROACH
================================================================================

What is mobile-first?
  Mobile (400w) is PRIMARY size
  Tablet (800w) is SECONDARY size
  Desktop (1200w) is TERTIARY size

Why mobile-first?
  - Mobile users get smallest images (400w)
  - Faster loading on mobile
  - Lower bandwidth usage
  - Better battery life
  - Better user experience

How it works:
  1. Browser detects viewport width
  2. Selects appropriate image size from srcset
  3. Mobile (≤768px): Loads 400w (80KB)
  4. Tablet (769-1024px): Loads 800w (150KB)
  5. Desktop (>1024px): Loads 1200w (250KB)

================================================================================
COMPRESSION STRATEGY
================================================================================

Mobile (400w):  Quality 65 → 80KB
Tablet (800w):  Quality 70 → 150KB
Desktop (1200w): Quality 75 → 250KB

Why aggressive compression?
  - Quality 65 WebP ≈ Quality 85 JPEG
  - Imperceptible difference on mobile screens
  - Excellent balance of quality and size
  - 84% reduction per image

================================================================================
LCP OPTIMIZATION
================================================================================

What is LCP?
  Largest Contentful Paint - when largest image/text appears

Why optimize LCP?
  - Affects mobile Lighthouse score
  - Affects user perception of speed
  - Critical for mobile performance

How to optimize:
  1. Add preload link in <head>
  2. Add fetchpriority="high" to <img>
  3. Remove lazy loading
  4. Use 400w variant (mobile gets smallest)
  5. Result: LCP 4-5s → 1.5-2s

================================================================================
LAZY LOADING STRATEGY
================================================================================

LCP Image (Hero):
  - NO lazy loading
  - fetchpriority="high"
  - Preload in <head>
  - Loads immediately

Below-fold Images (Gallery):
  - WITH lazy loading
  - loading="lazy"
  - Loads on scroll
  - Saves bandwidth

Result:
  - Hero loads immediately (critical)
  - Gallery loads on demand (efficient)
  - 30-40% bandwidth savings
