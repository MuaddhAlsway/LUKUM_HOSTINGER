FLOW 3: CLICKING EXHIBITION → EVENT DETAIL PAGE
════════════════════════════════════════════════

User clicks: Exhibition slide in carousel
    ↓ Link: event.php?title=exhibition-slug&lang=en
    ↓ Page navigates to: event.php
    ↓ event.php loads
    ↓ JavaScript: loadEventData() function called (line ~283)
    ↓ Gets URL params: title="exhibition-slug", lang="en"
    │
    ├─→ Determines if title is numeric ID or text slug
    │   Since title is "exhibition-slug" (text), uses:
    │   API URL = /api/get_event_details.php?title=exhibition-slug&lang=en
    │
    ├─→ api/get_event_details.php receives title parameter
    │   ├─ Looks up exhibition by slug/title
    │   ├─ Query (for exhibitions): SELECT ... event_video ... FROM exhibitions WHERE id=?
    │   │   Fields returned:
    │   │   - event_video (direct column name)
    │   │   - video_url (alias: ex.event_video as video_url)
    │   │   - Plus all other fields
    │   ├─ Fetches gallery images
    │   └─ Returns: { success: true, event: {..., event_video: "https://youtu.be/...", video_url: "https://youtu.be/...", ...}, gallery: [...] }
    │
    ↓ JavaScript receives API response
    ↓ displayEvent() function called with event object (line ~402)
    ↓ displayEvent checks for video URLs (line ~436):
    │   const videoUrl = event.video_url || event.event_video;
    │
    ├─→ IF videoUrl exists:
    │   ├─ Calls: displayVideo(videoUrl)
    │   ├─ displayVideo() function processes URL (line ~461):
    │   │   1. Gets videoSection element: document.getElementById('videoSection')
    │   │   2. Gets videoFrame element: document.getElementById('event-video')
    │   │   3. Parses URL (YouTube or Vimeo format)
    │   │   4. Extracts video ID
    │   │   5. Generates embed URL: https://www.youtube.com/embed/VIDEO_ID
    │   │   6. Sets iframe src: videoFrame.src = embedUrl
    │   │   7. Adds active class: videoSection.classList.add('active')
    │   └─ CSS rule triggers: .event-section--video.active { display: block !important; }
    │
    ├─→ Video section becomes visible ✅
    └─→ Video plays in embedded iframe ✅

STATUS: Video should be displaying on event page

TECHNICAL DETAILS BY FILE

event.php (Main Page)
━━━━━━━━━━━━━━━━━━━━━
- HTML: Video section with id="videoSection" and id="event-video" iframe
- Default: style="display: none;" (hidden by default)
- CSS: event-detail.css adds .active class to show
- JavaScript: Calls displayVideo() when video URL detected
- Logging: Enhanced console.log statements for debugging

api/get_event_details.php (API Endpoint)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Accepts: ?id=NUM or ?title=SLUG
- Returns: Complete event object with all fields
- For exhibitions: Includes both event_video and video_url fields
- Response: JSON with event, gallery, source, language

event-detail.css (Styling)
━━━━━━━━━━━━━━━━━━━━━━━
- Default: .event-section--video { display: none; }
- When active: .event-section--video.active { display: block !important; }
- Padding and background styling

exhibitions table (Database)
━━━━━━━━━━━━━━━━━━━━━━━━━
- Column: event_video (VARCHAR 500)
- Stores: Full video URL (e.g., https://www.youtube.com/watch?v=...)
- Can be: NULL or filled with URL

REQUIRED CONDITIONS FOR VIDEO TO DISPLAY

✅ Exhibition has event_video field filled (not NULL)
✅ Exhibition date is in the PAST (exhibitions require past dates)
✅ Video URL format is valid (YouTube or Vimeo)
✅ Video URL is publicly accessible
✅ api/get_event_details.php returns event_video field
✅ event.php receives video URL in event object
✅ displayVideo() function is called with valid URL
✅ displayVideo() successfully parses URL and generates embed URL
✅ displayVideo() successfully adds 'active' class
✅ event-detail.css is loaded and .active rule is applied
✅ Browser allows iframe rendering (no CSP violations)

KEY VARIABLES & THEIR MEANING

videoUrl = event.video_url || event.event_video
    → The video URL extracted from API response
    → Should be: "https://www.youtube.com/watch?v=..." OR null

embedUrl = "https://www.youtube.com/embed/VIDEO_ID"
    → The processed URL used in iframe src
    → YouTube URLs converted to embed format

videoId = "JH3zXmuFARw"
    → The extracted video identifier
    → Used to construct embed URL

videoSection.classList.contains('active')
    → Determines if video section is shown
    → Should be: true (when video exists)

videoFrame.src
    → The iframe src attribute value
    → Should be: "https://www.youtube.com/embed/VIDEO_ID..."
