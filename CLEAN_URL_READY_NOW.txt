HOW IT WORKS
================================================================================

1. User visits: /event/dior-exhibition?lang=en
2. Hostinger finds: /event/dior-exhibition.php (physical file)
3. File includes: event.php
4. event.php reads: $slug = basename(__FILE__, '.php'); → "dior-exhibition"
5. PHP passes to JavaScript: window.LAKUM_EVENT_SLUG = "dior-exhibition"
6. JavaScript fetches: api/get_event_details.php?id=dior-exhibition&lang=en
7. Event displays correctly ✅
