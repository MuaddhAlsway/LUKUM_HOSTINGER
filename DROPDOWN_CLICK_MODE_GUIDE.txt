HOW IT WORKS:
═══════════════════════════════════════════════════════════════════════════════

DESKTOP:
  1. Click on "Home" arrow
  2. Dropdown expands below with nav background color
  3. Arrow rotates 180° (↓ becomes ↑)
  4. Click item → Navigate to section
  5. Click "Home" again → Dropdown closes
  6. Click outside dropdown → Closes
  7. Press ESC → Closes

MOBILE (Same behavior):
  1. Tap "Home" arrow
  2. Dropdown expands with nav background color
  3. Arrow rotates 180°
  4. Tap item → Navigate to section
  5. Tap arrow again → Closes
  6. Tap outside → Closes
  7. Press ESC → Closes

CSS CHANGES MADE:
═══════════════════════════════════════════════════════════════════════════════

.lakum-nav__dropdown {
    background: transparent !important;      ← Uses parent background
    opacity: 0 !important;                   ← Hidden by default
    visibility: hidden !important;           ← Hidden by default
    pointer-events: none !important;         ← Not clickable
}

.lakum-nav__item--dropdown.active .lakum-nav__dropdown {
    opacity: 1 !important;                   ← Visible when clicked
    visibility: visible !important;          ← Visible when clicked
    pointer-events: auto !important;         ← Clickable when visible
    background: inherit !important;          ← Inherits nav color
}


JAVASCRIPT BEHAVIOR:
═══════════════════════════════════════════════════════════════════════════════

Event: Click on dropdown toggle (arrow button)

Action:
  1. Prevent default behavior
  2. Stop event propagation
  3. Close all other dropdowns
  4. Toggle .active class on parent item
  5. Update aria-expanded attribute
  6. Dropdown appears/disappears

Click outside:
  1. Close all open dropdowns
  2. Remove .active class

ESC key:
  1. Close all open dropdowns
  2. Remove .active class
