WHAT WAS FIXED
================================================================================

ISSUE: Dropdown menu was not visible/working on DESKTOP (1025px+) when clicked

THREE MAIN PROBLEMS FIXED:

1. JAVASCRIPT BUG (CRITICAL)
   File: js/lakum-header-dropdowns.js
   Problem: Outside click handler had early return on desktop
   Line: handleOutsideClick() function had: if (!isMobile) return;
   Fix: Rewrote to work on BOTH desktop and mobile
   
   BEFORE:
   function handleOutsideClick(event) {
       const isMobile = window.innerWidth <= MOBILE_BREAKPOINT;
       if (!isMobile) return; // <-- WRONG: Returns on desktop!
       // ...
   }
   
   AFTER:
   function handleOutsideClick(event) {
       const clickedInsideDropdown = Array.from(dropdownItems).some(item => {
           return item.contains(event.target);
       });
       if (!clickedInsideDropdown) {
           closeAllDropdowns(); // Works on desktop NOW!
       }
   }

2. CSS Z-INDEX & VISIBILITY (IMPORTANT)
   File: lakum-header-dropdowns.css
   Problem: Dropdown had low z-index (9999) and nav container missing positioning
   Fixes Applied:
   - .lakum-nav: Added z-index: 100 and position: relative
   - .lakum-nav__list: Added position: relative
   - .lakum-nav__dropdown: Increased z-index from 9999 to 99999
   - .lakum-nav__dropdown: Added explicit display: block
   - @media (min-width: 1025px): Added visibility: visible, opacity: 1, pointer-events: auto

3. CACHE BUSTING (TECHNICAL)
   File: includes/stylesheets.php
   Action: Updated dropdown CSS version from 2.2.0 to 2.4.0
   Why: Forces browser to download fresh CSS, not cached version

================================================================================
CACHE BUSTING EXPLAINED
================================================================================

New CSS version: 2.4.0 (was 2.2.0)

This means the browser will treat it as a new file:
OLD: lakum-header-dropdowns.css?v=2.2.0
NEW: lakum-header-dropdowns.css?v=2.4.0

Browser cache sees ?v=2.4.0 and says "that's different, download it fresh!"

If it still looks broken, do a hard refresh:
- Windows: Ctrl + Shift + R
- Mac: Cmd + Shift + R
- Chrome on Mac: Cmd + Shift + Delete
