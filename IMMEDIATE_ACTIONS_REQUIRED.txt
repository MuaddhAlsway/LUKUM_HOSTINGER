DROPDOWN NAVIGATION FIX - IMMEDIATE ACTIONS REQUIRED
================================================================================

PROBLEM FIXED:
- Dropdown navigation was not showing on desktop (≥821px)
- Root cause: Conflicting media query breakpoints

ROOT CAUSE:
The CSS had two competing rules for screens between 821px-1024px:
  1. @media (min-width: 821px) → showed nav
  2. @media (max-width: 1024px) → hid nav ← THIS ONE WON
The last rule in the cascade wins, so nav stayed hidden.

WHY THE FIX WORKS:
================================================================================

OLD CSS (Broken):
  @media (min-width: 821px) { .lakum-nav { display: flex; } }
  @media (max-width: 1024px) { .lakum-nav { display: none; } }
  
  Result for 821-1024px: display: none wins ❌

NEW CSS (Fixed):
  @media (min-width: 821px) { .lakum-nav { display: flex; } }
  @media (max-width: 820px) { .lakum-nav { display: none; } }
  
  Result for 821-1024px: display: flex wins ✅
  Result for ≤820px: display: none wins ✅

Plus:
  ✅ Dropdown background changed to #f6f6eb (header color)
  ✅ Dropdown links now visible with proper background
  ✅ Arrow rotation changed to click-based (not hover)
