───────────────────────────────────────────────────────────────────────────────
PROBLEM
───────────────────────────────────────────────────────────────────────────────

.app-nav__item elements existed in DOM but were invisible:
  ✅ Elements present in DevTools
  ❌ Width: 0 (collapsed)
  ❌ Not visible on page
  ❌ Text not rendered

───────────────────────────────────────────────────────────────────────────────
ROOT CAUSE
───────────────────────────────────────────────────────────────────────────────

1. min-width: 0 on .app-nav container
   → Forced flex items to collapse to 0 width

2. No width constraint on .app-nav__item
   → Items inherited parent collapse

3. Desktop CSS overrode mobile visibility
   → Mobile rules didn't fully reset constraints

TECHNICAL EXPLANATION
───────────────────────────────────────────────────────────────────────────────

CSS Flexbox Issue:

  .app-nav {
      flex: 1;           ← Expand to fill space
      min-width: 0;      ← But can shrink to 0 ← PROBLEM
  }

  Result: Container expands but items collapse to 0 width

Solution:

  .app-nav {
      flex: 1;           ← Expand to fill space
      /* min-width: 0 removed */
  }

  .app-nav__item {
      flex-shrink: 0;    ← Don't shrink
      width: auto;       ← Maintain content width
  }

  Result: Container expands AND items maintain width
