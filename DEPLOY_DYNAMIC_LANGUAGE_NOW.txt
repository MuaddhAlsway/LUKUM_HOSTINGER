HOW IT WORKS NOW
================================================================================

FLOW: User visits blog.php?lang=ar

1. User clicks: blog.php?lang=ar
2. PHP detects ?lang=ar parameter
3. PHP sets: window.LAKUM_LANG = 'ar'
4. JavaScript reads: window.LAKUM_LANG = 'ar'
5. JavaScript calls: api/get_blogs_working.php?lang=ar
6. API receives: lang='ar' parameter
7. API queries database with CASE statement
8. Database returns: Arabic content
9. Page displays: In Arabic

FLOW: User switches language

1. User clicks EN/AR button
2. LanguageManager.setLanguage('ar')
3. Page reloads with ?lang=ar
4. Flow repeats from step 1

FLOW: User visits without language parameter

1. User clicks: blog.php (no ?lang)
2. PHP checks localStorage or defaults to 'en'
3. PHP sets: window.LAKUM_LANG = 'en'
4. Rest of flow same as above
