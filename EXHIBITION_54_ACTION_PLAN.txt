WHAT HAPPENS IN BACKGROUND:
───────────────────────────────────────────────────────────────────────────────

1. Admin → adds video URL → saves form

2. JavaScript calls: api/edit_exhibition.php
   POST data: { id: 54, event_video: "https://..." }

3. API updates database:
   UPDATE exhibitions SET event_video = "..." WHERE id = 54

4. Database stores URL in event_video column

5. User goes to spaces.php

6. spaces.php loads exhibitions from api/get_exhibitions.php

7. User clicks exhibition

8. Redirects to: event.php?title=cheval-blanc

9. event.php calls: api/get_event_details.php?title=cheval-blanc

10. API finds exhibition in exhibitions table
    Returns: video_url AND event_video fields

11. event.php checks: const videoUrl = event.video_url || event.event_video

12. videoUrl = "https://..."

13. Calls: displayVideo(videoUrl)

14. displayVideo parses URL and creates iframe

15. Video embeds in page ✓
