3. Check DevTools:

   - Check "Computed" tab
   - Should show: display: flex
4. Check console for errors
5. Verify screen width > 768px

Base Rule (Always applies):
  .lakum-nav {
    display: flex !important;
    visibility: visible !important;
    opacity: 1 !important;
  }

Desktop Override (769px+):
  @media (min-width: 769px) {
    .lakum-nav { display: flex !important; }
    .lakum-header__mobile-toggle { display: none !important; }
    .lakum-nav--mobile { display: none !important; }
  }

Mobile Override (< 768px):
  @media (max-width: 768px) {
    .lakum-nav { display: none !important; }
    .lakum-header__mobile-toggle { display: flex !important; }
    .lakum-nav--mobile { display: flex !important; }
  }
