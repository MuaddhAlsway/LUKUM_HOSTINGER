"Make sure .lakum-nav__dropdown (inside .lakum-nav__item) 
appears BELOW it based on lakum-nav__item"

MEANING:
├─ .lakum-nav__dropdown is nested inside .lakum-nav__item ✓
├─ It should appear BELOW the header (not at top)
├─ It should be positioned based on WHICH nav item was clicked
├─ English: Dropdown on LEFT
├─ Arabic: Dropdown on RIGHT
└─ Both: Aligned with the clicked nav item

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

HOW IT WORKS:

1. HTML Structure (NO CHANGES):
   └─ .lakum-nav__dropdown stays nested inside .lakum-nav__item
      (This is correct semantic HTML)

2. CSS Sets Container (v1.2.0):
   └─ position: fixed;  ← Breaks out of parent flow
   └─ NO hardcoded top/left/right (JavaScript controls them)
   └─ Other styling: background, border, shadow, opacity, etc.

3. JavaScript Calculates Position:
   ├─ Get nav item's position: getBoundingClientRect()
   ├─ Calculate top: headerHeight (80px) + gap (10px) = 90px
   ├─ Detect language: RTL (Arabic) or LTR (English)
   ├─ If LTR: left = item's left position, right = auto
   ├─ If RTL: right = calculated offset, left = auto
   └─ Apply inline styles to .lakum-nav__dropdown

4. Result:
   └─ Dropdown appears BELOW header (top: 90px)
   └─ Aligned with clicked nav item
   └─ English: on LEFT side
   └─ Arabic: on RIGHT side

HOW JAVASCRIPT POSITIONS THE DROPDOWN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Get nav item position
────────────────────────────
const itemRect = dropdownItem.getBoundingClientRect();
│
└─ Returns: { left, right, top, bottom, width, height }
   Example: { left: 154, right: 200, top: 10, bottom: 70, ... }


STEP 2: Calculate dropdown top (same for all)
─────────────────────────────────────────────
const headerHeight = 80;
const dropdownTop = headerHeight + 10;  // 90px from viewport top
│
└─ This puts dropdown BELOW header with 10px gap


STEP 3: Detect language
──────────────────────
const isRTL = document.documentElement.dir === 'rtl';
│
└─ isRTL = false (English/LTR)
└─ isRTL = true (Arabic/RTL)


STEP 4a: Position for English (LTR)
───────────────────────────────────
dropdown.style.left = itemRect.left + 'px';   // 154px
dropdown.style.right = 'auto';
│
└─ Dropdown appears on LEFT, aligned with nav item


STEP 4b: Position for Arabic (RTL)
──────────────────────────────────
const rightOffset = window.innerWidth - itemRect.right;
dropdown.style.right = rightOffset + 'px';   // 1046px (for 1200px window)
dropdown.style.left = 'auto';
│
└─ Dropdown appears on RIGHT, aligned with nav item


STEP 5: Apply all positioning
──────────────────────────────
dropdown.style.position = 'fixed';
dropdown.style.top = dropdownTop + 'px';       // 90px
// + left/right set above


RESULT:
───────
Dropdown appears BELOW header, aligned with clicked nav item!
