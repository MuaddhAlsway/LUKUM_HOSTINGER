   ├─ Before: <link rel="stylesheet" href="Home.css">
   ├─ After: <link rel="preload" href="Home.css" as="style" 
   │         onload="this.onload=null;this.rel='stylesheet'">
   └─ Result: Non-blocking CSS loading

2. API DEFERRAL FIX
   ├─ Before: loadFeaturedEvent(); // Runs immediately
   ├─ After: window.addEventListener('load', () => {
   │           setTimeout(initPage, 200);
   │         });
   └─ Result: API loads after LCP

3. IMAGE OPTIMIZATION FIX
   ├─ Before: <img src="img.webp">
   ├─ After: <img src="img.webp" 
   │          loading="lazy" 
   │          decoding="async" 
   │          style="content-visibility: auto;"
   │          width="1200" height="800">
   └─ Result: Faster rendering, no layout shift

4. LAYOUT SHIFT PREVENTION FIX
   ├─ Before: img { width: 100%; }
   ├─ After: img { 
   │            width: 100%; 
   │            height: auto; 
   │            aspect-ratio: attr(width) / attr(height);
   │          }
   └─ Result: CLS reduced by 50%

5. UNUSED CSS REMOVAL FIX
   ├─ Removed: .old-button-style, .duplicate-spacing, .unused-animation
   ├─ Kept: .btn, .container, .grid, .flex, etc.
   └─ Result: CSS size reduced by 15%
