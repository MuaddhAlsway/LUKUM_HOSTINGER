================================================================================
HOW IT WORKS
================================================================================

1. User visits: /event/dior-exhibition?lang=en
2. Hostinger finds: /event/dior-exhibition.php (physical file)
3. File includes: event.php (main detail page)
4. event.php reads: $slug = basename(__FILE__, '.php');
5. Gets slug: "dior-exhibition"
6. Queries database: SELECT * FROM events WHERE slug = 'dior-exhibition'
7. Displays: Event details page
