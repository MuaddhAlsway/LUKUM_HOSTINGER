┌─ SLUG HELPER FUNCTIONS ───────────────────────────────────────────────────────┐
│                                                                                 │
│  SlugHelper::generate($text)                                                   │
│  ─────────────────────────────────────────────────────────────────────────     │
│  Generates URL-friendly slug from text                                         │
│  Example: SlugHelper::generate('My Blog Post') → 'my-blog-post'               │
│                                                                                 │
│  SlugHelper::validate($slug)                                                   │
│  ─────────────────────────────────────────────────────────────────────────     │
│  Validates slug format                                                         │
│  Example: SlugHelper::validate('my-blog-post') → true                         │
│                                                                                 │
│  SlugHelper::sanitize($slug)                                                   │
│  ─────────────────────────────────────────────────────────────────────────     │
│  Ensures slug is valid                                                         │
│  Example: SlugHelper::sanitize('My Blog Post') → 'my-blog-post'               │
│                                                                                 │
│  SlugHelper::fromTitle($title)                                                 │
│  ─────────────────────────────────────────────────────────────────────────     │
│  Converts title to slug (backward compatibility)                               │
│  Example: SlugHelper::fromTitle('My Blog Post') → 'my-blog-post'              │
│                                                                                 │
│  SlugHelper::generateUnique($text, $table)                                     │
│  ─────────────────────────────────────────────────────────────────────────     │
│  Generates unique slug with auto-increment                                     │
│  Example: SlugHelper::generateUnique('My Blog Post', 'blogs')                 │
│           → 'my-blog-post' or 'my-blog-post-1' if duplicate                   │
│                                                                                 │
│  SlugHelper::extract($_GET)                                                    │
│  ─────────────────────────────────────────────────────────────────────────     │
│  Extracts slug from URL parameters                                             │
│  Example: SlugHelper::extract($_GET) → 'my-blog-post'                         │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
