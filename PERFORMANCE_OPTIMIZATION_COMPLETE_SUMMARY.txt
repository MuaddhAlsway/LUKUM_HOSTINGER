──────────────────

<link rel="preload" as="image" href="hero-1600.webp" fetchpriority="high">

🔧 TROUBLESHOOTING
================================================================================

ISSUE: Cache not working
SOLUTION:
  // Check cache stats
  api.getCacheStats()
  
  // Clear cache if needed
  api.cache.clear()
  
  // Enable debug mode
  window.apiCache = new APICacheManager({ debug: true })

ISSUE: CSS not loading
SOLUTION:
  • Check .htaccess for correct MIME types
  • Verify CSS file paths are correct
  • Check browser console for 404 errors
  • Clear browser cache (Ctrl+Shift+Delete)

ISSUE: Images not optimizing
SOLUTION:
  • Verify api/image-helper.php is accessible
  • Check image file permissions
  • Verify WebP support in browser

ISSUE: Lighthouse score not improving
SOLUTION:
  • Clear browser cache completely
  • Run audit in incognito mode
  • Check for render-blocking resources
  • Verify all optimizations are deployed
