================================================================================
  CHANGES APPLIED
================================================================================

For each page, added to <head> section:

  <!-- Preload LCP image with high priority -->
  <link rel="preload" as="image" href="assest/img-4-1200w.webp" fetchpriority="high">
  <link rel="preload" as="image" href="assest/img-4.webp" fetchpriority="high">

WHY THIS WORKS:
  • rel="preload"        → Start loading immediately
  • as="image"           → Specify resource type
  • href="image.webp"    → Image URL
  • fetchpriority="high" → Highest priority in queue

RESULT:
  • Images load immediately (not deferred)
  • Highest priority in resource queue
  • Responsive sizes for all devices
  • 60-75% faster LCP
