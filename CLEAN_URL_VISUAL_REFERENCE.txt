┌─ HOW IT WORKS ────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  USER VISITS                                                                    │
│  ↓                                                                              │
│  /event/dior-exhibition?lang=en                                                │
│  ↓                                                                              │
│  .HTACCESS REWRITES TO                                                          │
│  ↓                                                                              │
│  event.php?slug=dior-exhibition&lang=en                                        │
│  ↓                                                                              │
│  PHP RECEIVES                                                                   │
│  ↓                                                                              │
│  $_GET['slug'] = 'dior-exhibition'                                             │
│  $_GET['lang'] = 'en'                                                          │
│  ↓                                                                              │
│  FETCHES FROM API                                                               │
│  ↓                                                                              │
│  api/get_events.php?slug=dior-exhibition&lang=en                               │
│  ↓                                                                              │
│  DATABASE QUERY                                                                 │
│  ↓                                                                              │
│  SELECT * FROM events WHERE slug = 'dior-exhibition'                           │
│  ↓                                                                              │
│  RETURNS EVENT DATA                                                             │
│  ↓                                                                              │
│  PAGE DISPLAYS EVENT                                                            │
│                                                                                 │
