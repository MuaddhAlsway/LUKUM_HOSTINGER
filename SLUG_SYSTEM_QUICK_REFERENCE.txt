───────────────────────────────────────────────────────────────────────────────
SLUG GENERATION
───────────────────────────────────────────────────────────────────────────────

English Title → Slug:

  "How to Optimize Performance"
    ↓
  "how-to-optimize-performance"

Process:
  1. Take title_en from database
  2. Convert to lowercase
  3. Replace spaces with hyphens
  4. Remove special characters
  5. Keep only alphanumeric and hyphens

Code:
  const titleSlug = englishTitle
      .toLowerCase()
      .replace(/\s+/g, '-')           // spaces → hyphens
      .replace(/[^\w-]/g, '');        // remove special chars

───────────────────────────────────────────────────────────────────────────────
LANGUAGE SUPPORT
───────────────────────────────────────────────────────────────────────────────

English (Default):
  URL: blogPageDetails.php?title=blog-post-slug
  Content: English

Arabic:
  URL: blogPageDetails.php?title=blog-post-slug&lang=ar
  Content: Arabic
  Slug: Still English (SEO-friendly)

Key Point:
  - Slug is ALWAYS in English (from title_en)
  - Language parameter (?lang=ar) controls content language
  - Arabic content fetched based on language, not slug

───────────────────────────────────────────────────────────────────────────────
AUTOMATIC REDIRECT
───────────────────────────────────────────────────────────────────────────────

Old ID URLs Auto-Redirect:

  User visits:
    blogPageDetails.php?id=14&lang=en
    ↓
  System fetches blog with ID 14
    ↓
  Generates slug from title_en
    ↓
  Redirects to:
    blogPageDetails.php?title=blog-post-slug&lang=en

Benefit:
  - Old links still work
  - Automatic SEO-friendly redirect
  - No broken links

───────────────────────────────────────────────────────────────────────────────
SLUG LOOKUP
───────────────────────────────────────────────────────────────────────────────

When user visits slug URL:

  1. Fetch all blogs from API
  2. Generate slug for each blog's title_en
  3. Find blog where generated slug matches URL slug
  4. Load that blog's content

Example:
  URL: blogPageDetails.php?title=performance-optimization-tips
  
  System generates slugs:
    Blog 1: "web-design-trends" (no match)
    Blog 2: "performance-optimization-tips" (MATCH!)
    Blog 3: "seo-best-practices" (no match)
  
  Loads Blog 2 content
