RESPONSIVE DESIGN PRINCIPLES
================================================================================

1. Mobile-First
   Start with mobile, enhance for larger screens

2. Progressive Enhancement
   Add features as screen size increases

3. Breakpoint Strategy
   480px → 768px → 820px → 1024px → 1200px+

4. Content Priority
   Most important content first on mobile

5. Touch-Friendly
   Minimum 44px touch targets

6. Performance
   Optimize for each breakpoint

7. Accessibility
   Maintain at all sizes
