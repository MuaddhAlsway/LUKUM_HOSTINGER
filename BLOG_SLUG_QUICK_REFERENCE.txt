═══════════════════════════════════════════════════════════════════════════════
  HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════

1. User clicks blog card in blog.php
2. getBlogUrl() generates slug from blog.slug or blog.title_en
3. URL: blogPageDetails.php?title=behind-the-scenes&lang=en
4. blogPageDetails.php receives slug
5. API fetches blog by slug
6. Page displays blog content

═══════════════════════════════════════════════════════════════════════════════
  SLUG GENERATION LOGIC
═══════════════════════════════════════════════════════════════════════════════

const slug = (blog.slug || blog.title_en || blog.title || 'blog')
    .toLowerCase()                    // Convert to lowercase
    .replace(/\s+/g, '-')            // Replace spaces with hyphens
    .replace(/[^\w-]/g, '');         // Remove special characters

═══════════════════════════════════════════════════════════════════════════════
  PRIORITY ORDER
═══════════════════════════════════════════════════════════════════════════════

1. blog.slug (from database)
2. blog.title_en (English title)
3. blog.title (Fallback title)
4. 'blog' (Default)
