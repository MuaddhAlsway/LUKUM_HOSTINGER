================================================================================
  🚀 LCP (LARGEST CONTENTFUL PAINT) OPTIMIZATION - COMPLETE GUIDE
================================================================================

PROBLEM:
  Your LCP image is lazy-loaded, which delays rendering and hurts performance.
  
  Current (Bad):
    <img src="assest/blog-uploads/blog-1772395557-69a49c25b8365.webp" 
         alt="Snapchat" 
         loading="lazy">
  
  Impact:
    ❌ LCP: 4-5 seconds (should be <2.5s)
    ❌ FCP: 3-4 seconds (should be <1.8s)
    ❌ Lighthouse: 40-50 (should be 85+)
    ❌ Image loads deferred until scroll

================================================================================
  SOLUTION: 5-STEP LCP OPTIMIZATION
================================================================================

STEP 1: REMOVE LAZY LOADING
  ❌ Remove: loading="lazy"
  ✅ Reason: LCP images must load eagerly, not deferred

STEP 2: ADD HIGH PRIORITY
  ✅ Add: fetchpriority="high"
  ✅ Reason: Tells browser this image is critical

STEP 3: PRELOAD IN HEAD
  ✅ Add in <head>:
    <link rel="preload" as="image" href="image.webp" fetchpriority="high">
  ✅ Reason: Start loading immediately when page loads

STEP 4: ADD RESPONSIVE SIZES
  ✅ Add: srcset and sizes attributes
  ✅ Reason: Correct size for each device

STEP 5: KEEP ASYNC DECODING
  ✅ Keep: decoding="async"
  ✅ Reason: Prevent blocking main thread

================================================================================
  OPTIMIZED CODE
================================================================================

IN <HEAD> SECTION:
  <!-- Preload LCP image with high priority -->
  <link rel="preload" 
        as="image" 
        href="assest/blog-uploads/blog-1772395557-69a49c25b8365.webp"
        fetchpriority="high">

IN <BODY> WHERE IMAGE IS DISPLAYED:
  <!-- ✅ OPTIMIZED FOR LCP -->
  <img src="assest/blog-uploads/blog-1772395557-69a49c25b8365.webp"
       srcset="assest/blog-uploads/blog-1772395557-69a49c25b8365-400w.webp 400w,
               assest/blog-uploads/blog-1772395557-69a49c25b8365-800w.webp 800w,
               assest/blog-uploads/blog-1772395557-69a49c25b8365-1200w.webp 1200w"
       sizes="(max-width: 640px) 100vw, (max-width: 1024px) 90vw, 1200px"
       alt="Snapchat"
       fetchpriority="high"
       decoding="async"
       width="1200"
       height="800">

================================================================================
  WHY THIS WORKS
================================================================================

Attribute              Purpose                          Impact
─────────────────────────────────────────────────────────────────────────────
rel="preload"          Start loading immediately        30-40% faster load
fetchpriority="high"   Highest priority in queue        Loads before others
Remove loading="lazy"  Load eagerly, not deferred       Eliminates delay
srcset + sizes         Responsive images               Correct size/device
decoding="async"       Non-blocking decode             No main thread block
width + height         Aspect ratio                    Prevents CLS

================================================================================
  COMMON MISTAKES TO AVOID
================================================================================

❌ WRONG:
  <img src="image.webp" loading="lazy" fetchpriority="high">
  (Still has lazy loading - defeats the purpose)

❌ WRONG:
  <img src="image.webp" fetchpriority="high">
  (No preload in head - slower loading)

❌ WRONG:
  <img src="image.webp" fetchpriority="high" decoding="sync">
  (Blocking decode - blocks main thread)

❌ WRONG:
  <img src="image.webp" fetchpriority="high">
  (No width/height - causes layout shift)

✅ CORRECT:
  <!-- In <head> -->
  <link rel="preload" as="image" href="image.webp" fetchpriority="high">
  
  <!-- In body -->
  <img src="image.webp"
       srcset="image-400w.webp 400w, image-800w.webp 800w, image-1200w.webp 1200w"
       sizes="(max-width: 640px) 100vw, (max-width: 1024px) 90vw, 1200px"
       alt="Description"
       fetchpriority="high"
       decoding="async"
       width="1200"
       height="800">

================================================================================
  RESPONSIVE SIZES EXPLAINED
================================================================================

sizes="(max-width: 640px) 100vw, (max-width: 1024px) 90vw, 1200px"

  Mobile (≤640px):    100% of viewport width
  Tablet (≤1024px):   90% of viewport width
  Desktop (>1024px):  1200px fixed width

This tells browser how much space the image will take on each device.

================================================================================
  SRCSET EXPLAINED
================================================================================

srcset="image-400w.webp 400w,
        image-800w.webp 800w,
        image-1200w.webp 1200w"

  400w:  Use this image for viewports up to 400px
  800w:  Use this image for viewports up to 800px
  1200w: Use this image for viewports 1200px and above

Browser automatically chooses the best size for the device.
