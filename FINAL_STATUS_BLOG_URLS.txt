================================================================================
TECHNICAL DETAILS
================================================================================

URL GENERATION (blog.php):
  const getBlogUrl = (blog) => {
      const title = blog.title_en || blog.title || 'blog';
      const lang = window.LAKUM_LANG || localStorage.getItem('lakum_language') || 'en';
      return `blogPageDetails.php?title=${encodeURIComponent(title)}&lang=${lang}`;
  };

PARAMETER EXTRACTION (blogPageDetails.php):
  let blogIdentifier = new URLSearchParams(window.location.search).get('title');
  let urlLang = new URLSearchParams(window.location.search).get('lang');

LANGUAGE PRIORITY:
  1. URL parameter (?lang=ar or ?lang=en)
  2. Window language (window.LAKUM_LANG)
  3. LocalStorage (lakum_language)
  4. Default (en)

API RESPONSE (get_blogs_working.php):
  CASE 
      WHEN ? = 'ar' AND b.title_ar IS NOT NULL THEN b.title_ar
      ELSE COALESCE(b.title_en, b.title)
  END as title
