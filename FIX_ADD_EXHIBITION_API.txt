FIX: "Error: API returned empty response" in add-exhibition.html
================================================================================

PROBLEM:
  When trying to add a new exhibition via the admin panel, got error:
  "Error: API returned empty response"

ROOT CAUSE:
  The add_exhibition.php API was trying to load complex configuration files
  and if there were any PHP errors, they were suppressed, causing empty response.

SOLUTION APPLIED:
  Rewrote api/add_exhibition.php to be SIMPLE & ROBUST:
  ✅ Removed dependency on complex config files
  ✅ Direct database connection
  ✅ Proper error handling with clear messages
  ✅ Auto-creates exhibitions table if missing
  ✅ Output buffering to prevent stray output
  ✅ Clear JSON responses for all cases

FILES MODIFIED:
  • api/add_exhibition.php ← COMPLETELY REWRITTEN

KEY CHANGES:
  
  OLD (Broken):
    - Required db.php → config.php → config.local.php chain
    - Multiple levels of error suppression
    - No clear error messages if something failed
    - Empty response on any error
  
  NEW (Fixed):
    - Direct mysqli connection: new mysqli('localhost', 'root', '', 'lakum_artspace')
    - Clear error messages for debugging
    - Auto-creates exhibitions table if missing
    - Output buffering to catch stray PHP output
    - Returns clear JSON for all cases (success/error)

TROUBLESHOOTING:

If still getting errors:

1. Check database connection:
   - Database name: lakum_artspace
   - Host: localhost
   - User: root
   - Password: (empty)
   
   Open phpMyAdmin and verify you can access the database

2. Check if exhibitions table exists:
   SELECT * FROM exhibitions;
   
   If table doesn't exist, the API will auto-create it

3. Check browser console (F12):
   - Network tab → look at add_exhibition.php response
   - Should see JSON: {"success": true, ...}

4. Check server logs:
   - xampp/apache/logs/error.log
   - Look for PHP errors
