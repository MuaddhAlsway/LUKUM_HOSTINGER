WHY THIS MATTERS
══════════════════════════════════════════════════════════════════════════════

CSS Cascade Problem:
  When multiple files define same class, LAST loaded file WINS

  Before (CONFLICT):
    1. assest/lakum-header.css loads → .lakum-header { background: white; }
    2. lakum-components.css loads → .lakum-header { background: beige; }
    3. Result: Header is beige (WRONG!)

  After (NO CONFLICT):
    1. assest/lakum-header.css loads → .lakum-header { background: white; }
    2. lakum-components.css loads → (no header styles)
    3. Result: Header is white (CORRECT!)
