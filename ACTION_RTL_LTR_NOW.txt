================================================================================
HOW IT DETECTS LANGUAGE
================================================================================

JavaScript checks:
   if (document.documentElement.dir === 'rtl') {
       // Arabic - use RIGHT positioning
   } else {
       // English - use LEFT positioning
   }

This detects the HTML `dir` attribute:
   English: <html dir="ltr"> or <html> (no dir)
   Arabic: <html dir="rtl">

TECHNICAL SUMMARY
================================================================================

Position Calculation:

LTR (English):
   top = headerHeight + 10px      // Below header
   left = rect.left                // Item's left edge
   right = auto                    // Not used

RTL (Arabic):
   top = headerHeight + 10px      // Below header
   left = auto                    // Not used
   right = window.innerWidth - rect.right  // Calculate from right

Result:
   - English: Dropdown on LEFT ✅
   - Arabic: Dropdown on RIGHT ✅
   - Both: Below header + 10px gap ✅
   - Both: Aligned with clicked item ✅
