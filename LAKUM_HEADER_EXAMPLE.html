LAKUM Header Component

A complete, responsive header with mobile menu, active link detection, and language switching.

Features

📱 Responsive Design

Automatically adapts from desktop horizontal menu to mobile hamburger menu with smooth animations.

🎯 Active Link Detection

Automatically highlights the current page in the navigation menu based on the URL.

🌐 Language Support

Built-in language switcher with RTL support for Arabic and other right-to-left languages.

♿ Accessibility

Semantic HTML, ARIA labels, keyboard navigation, and focus management for all users.

⚡ Performance

Minimal JavaScript, CSS-based animations, and optimized for fast loading and smooth interactions.

🎨 Customizable

Easy to customize colors, sizes, and breakpoints using CSS variables and configuration.

How to Use

1. Add CSS to Head

<link rel="stylesheet" href="assest/lakum-header.css">

2. Add JavaScript Before Closing Body

<script src="assest/lakum-header.js" defer></script>

3. Use the HTML Structure

Copy the header HTML from this page or the example provided in the documentation.

Responsive Breakpoints

Desktop (1024px+)

Full horizontal navigation menu with hover effects and smooth underline animations.

Tablet (768px - 1023px)

Optimized spacing and font sizes with all desktop features maintained.

Mobile (<768px)

Hamburger menu with slide-down animation and optimized touch interactions.

Customization

Change Colors

Edit CSS variables in lakum-header.css:

:root { --header-active: #ff6b35; /* Active link color */ --header-bg: #ffffff; /* Background */ --header-text: #1a1a1a; /* Text color */ --header-hover: #f6f6eb; /* Hover background */ }

Change Header Height

:root { --header-height: 70px; /* Desktop height */ } @media (max-width: 768px) { :root { --header-height: 60px; /* Mobile height */ } }
