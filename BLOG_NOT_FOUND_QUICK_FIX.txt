  BLOG NOT FOUND - QUICK FIX GUIDE
═══════════════════════════════════════════════════════════════════════════════

ISSUE: {success: false, error: "Blog not found"}

CAUSE: The blog slug "behind-the-scenes-curation" doesn't exist in the database

═══════════════════════════════════════════════════════════════════════════════
  STEP 1: CHECK WHAT BLOGS EXIST
═══════════════════════════════════════════════════════════════════════════════

Visit this URL in your browser:
https://lakumartspace.com/api/debug-blogs-slugs.php

This will show:
✓ All blogs in the database
✓ Their IDs
✓ Their slugs
✓ Their titles

Look for a blog with title "Behind the Scenes Curation" or similar.

═══════════════════════════════════════════════════════════════════════════════
  STEP 2: TEST SLUG LOOKUP
═══════════════════════════════════════════════════════════════════════════════

If you found the blog, note its slug and test it:
https://lakumartspace.com/api/test-blog-slug-lookup.php?slug=YOUR-SLUG&lang=en

Replace YOUR-SLUG with the actual slug from Step 1.

This will show:
✓ If the slug works
✓ The blog data
✓ Any errors

═══════════════════════════════════════════════════════════════════════════════
  STEP 3: POSSIBLE SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

SOLUTION A: Blog doesn't exist
→ Create the blog in admin panel
→ Title: "Behind the Scenes Curation"
→ Slug will be auto-generated

SOLUTION B: Slug is different
→ Use the correct slug from Step 1
→ Update the blog page URL with correct slug

SOLUTION C: Slug column is empty
→ Run SQL to populate slugs:
   UPDATE blogs 
   SET slug = LOWER(REPLACE(title_en, ' ', '-'))
   WHERE slug IS NULL OR slug = '';

═══════════════════════════════════════════════════════════════════════════════
  STEP 4: UPDATE BLOG PAGE URL
═══════════════════════════════════════════════════════════════════════════════

Once you know the correct slug, update the URL:

CURRENT (WRONG):
https://lakumartspace.com/blogPageDetails.php?title=behind-the-scenes-curation&lang=en

CORRECT (with actual slug):
https://lakumartspace.com/blogPageDetails.php?title=ACTUAL-SLUG&lang=en
