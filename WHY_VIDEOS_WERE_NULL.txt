The problem was NOT in the code. The problem was in the database schema!

EXHIBITIONS TABLE (for past exhibitions):
  What API tried to save to:    exhibitions.event_video
  What actually existed:        ✓ id, title_en, description_en, ...
                                ✗ NO event_video column!
  
  Result: Data sent to DB → Column doesn't exist → Data discarded!

EVENTS TABLE (for upcoming events):
  What API tried to save to:    events.video_url
  What actually existed:        ✓ id, title, description, ...

  Result: Data sent to DB → Column doesn't exist → Data discarded!

Timeline:

1. Database created (old version)
   ├─ Had: title, description, location, dates, cover_image
   └─ Missing: event_video, video_url

2. Admin forms created
   ├─ add-exhibition.html with event_video field
   └─ add-event.html with video_url field

3. API code written
   ├─ add_exhibition.php tries to save event_video
   └─ add_event.php tries to save video_url

4. Frontend code written
   ├─ event.php tries to read video_url OR event_video
   └─ displayVideo() function ready

5. Everything looks good!
   └─ All code in place, ready to go

BUT...

6. Database columns never created!
   ├─ add_exhibition.php has CREATE TABLE IF NOT EXISTS
   ├─ But if table already exists, it doesn't add new columns
   ├─ And old database had exhibitions table WITHOUT columns
   └─ So new columns never got added!

Result: Code ready, database not ready!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
THE FIX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ALTER TABLE events ADD COLUMN video_url VARCHAR(500);
