================================================================================
WHY PAST EVENTS MIGHT NOT SHOW:
================================================================================

1. BROWSER CACHE
   - Page cached before exhibition was added
   - Hard refresh: Ctrl+Shift+Delete
   - Clear cache and reload

2. WRONG DATE SELECTED
   - Exhibition date must be TODAY or BEFORE
   - If you selected future date, won't show
   - Admin form only allows past dates

3. JSON PARSING ERROR
   - Check browser console (F12)
   - Look for red errors in Console tab

4. API NOT RETURNING DATA
   - Check: api/debug_exhibitions.php
   - Should list all exhibitions in database

5. FILTER NOT WORKING
   - Check: api/get_exhibitions.php returns data
   - Verify date format matches filter

EVERYTHING SHARES THE SAME DATABASE TABLE!

================================================================================
IMPORTANT: DATE FORMAT
================================================================================

Database format: YYYY-MM-DD (e.g., 2026-06-21)
JavaScript format: Also YYYY-MM-DD

Filter Logic:
  - Exhibition date (string): "2026-06-21"
  - Today (date): new Date().getHours(0,0,0,0)
  - Compare: date <= today
  - Result: Shows if date is today or before

Example:
  Today: 2026-06-21 (midnight)
  Exhibition 1: 2026-06-21 → SHOW ✓
  Exhibition 2: 2026-06-20 → SHOW ✓
  Exhibition 3: 2026-06-22 → DON'T SHOW ✗
