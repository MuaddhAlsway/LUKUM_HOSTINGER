KEY FEATURES
================================================================================
✅ Single Source of Truth
   - One PHP file for all headers
   - One CSS file for all header styles
   - One JS file for all header functionality
   - No duplication, no conflicts

✅ Aggressive Override Strategy
   - All CSS rules use !important to guarantee override
   - Scoped to .lakum-* classes to prevent conflicts
   - Eliminates z-index wars and specificity issues

✅ Proper Z-Index Hierarchy
   - --z-header: 1000 (base layer)
   - --z-overlay: 9999 (overlay behind nav)
   - --z-nav-content: 10000 (nav content)
   - --z-toggle: 10001 (toggle button on top)

✅ Mobile-First Responsive
   - Desktop: > 1024px (80px header)
   - Tablet: 768px - 1024px (70px header)
   - Mobile: < 768px (60px header)
   - Small mobile: < 480px (56px header)

✅ RTL Support Built-In
   - Automatic layout reversal for Arabic
   - Just add dir="rtl" to <html> tag
   - No duplicate CSS needed

✅ Accessibility First
   - Semantic HTML (header, nav, main, footer)
   - ARIA attributes (aria-expanded, aria-label, aria-current)
   - Keyboard navigation (ESC to close nav)
   - Focus management
   - Skip to main content link
   - High contrast mode support

✅ CSS Custom Properties
   - Easy to customize colors, heights, z-index
   - No need to edit multiple rules
   - Centralized configuration
