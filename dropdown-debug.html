🐛 Troubleshooting

  • Arrow not visible? → Check CSS: .dropdown-toggle { display: inline-flex !important; }
  • Dropdown doesn't appear? → Check CSS: .nav-item:hover .dropdown { opacity: 1; }
  • Dropdown clipped? → Check CSS: .nav { overflow: visible !important; }
  • Z-index issue? → Verify: .dropdown { z-index: 9999 !important; }
  • Styling not applying? → Clear cache and hard refresh (Ctrl+Shift+R)
