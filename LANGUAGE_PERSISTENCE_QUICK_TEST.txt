TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

IF LINKS OPEN IN WRONG LANGUAGE:
  1. Check URL parameter: ?lang=en or ?lang=ar
  2. Verify getCurrentLanguage() function exists
  3. Check browser console for errors
  4. Clear browser cache (Ctrl+Shift+Delete)

IF LINKS ARE BROKEN (404):
  1. Verify terms.php and privacy.php exist
  2. Check file paths are correct
  3. Verify .htaccess rules (if using clean URLs)

IF LANGUAGE SWITCHER DOESN'T WORK:
  1. Check language switcher JavaScript
  2. Verify localStorage is working
  3. Check browser console for errors
