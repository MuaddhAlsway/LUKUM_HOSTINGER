================================================================================
                               HOW IT WORKS NOW
================================================================================

DESKTOP (≥ 821px):
  1. User clicks dropdown arrow button
  2. JavaScript adds .active class to .lakum-nav__item--dropdown
  3. CSS shows the .lakum-nav__dropdown menu with opacity:1, visibility:visible
  4. Dropdown appears below the nav item
  5. User clicks a link or outside to close

MOBILE (≤ 820px):
  - Mobile off-canvas menu handles dropdowns
  - Desktop dropdown not visible

LANGUAGES:
  - English (LTR): Dropdown appears on LEFT
  - Arabic (RTL): Dropdown appears on RIGHT

================================================================================
                              CSS HIERARCHY (Z-INDEX)
================================================================================

.lakum-nav                    → relative, no z-index
.lakum-nav__list              → z-index: 1
.lakum-nav__item--dropdown    → z-index: 1001 ← Parent container
.lakum-nav__dropdown          → z-index: 1002 ← Always visible on top
.lakum-nav__dropdown-toggle   → z-index: 1001

================================================================================
                             OVERFLOW MANAGEMENT
================================================================================

CRITICAL: These must ALL be overflow: visible !important

.lakum-header                 → overflow: visible !important
.lakum-header__container      → overflow: visible !important
.lakum-nav                    → overflow: visible !important
.lakum-nav__list              → overflow: visible !important
.lakum-nav__item--dropdown    → overflow: visible !important

If ANY of these have overflow:hidden, the dropdown gets CLIPPED.

                                IF ISSUES
================================================================================

1. Open browser DevTools (F12)
2. Inspect .lakum-nav__dropdown element while it's "active"
3. Check Computed Styles:
   - opacity: should be 1
   - visibility: should be visible
   - z-index: should be 1002

4. Check if .active class is on parent (.lakum-nav__item--dropdown)
   - If not → JavaScript issue (check console for errors)
   - If yes but hidden → CSS not loading (check inline styles)

5. Force refresh page: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
